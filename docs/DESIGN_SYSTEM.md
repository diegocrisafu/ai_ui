# SceneBreaker design system

The canonical design system is [root DESIGN.md](../DESIGN.md). It records the current route laboratory's built tokens, component states, responsive behavior, font files and documented limits. Machine-readable extensions and component previews live in [.impeccable/design.json](../.impeccable/design.json) (schema version 2).

The current world uses cool porcelain, graphite and ultramarine; bold monochrome Familjen Grotesk headings and interface text, plus Azeret Mono measurements; the exact 1.25 type ramp with 150% leading; and 12/8/4 tracks. The previous Instrument Serif/coloured-italic headline was replaced at the user's request on October 8. Its assets and license remain archived, but are not loaded. The older cream/forest/rust and Uncut/Spline interface is also archived.

- [Familjen Grotesk](../public/fonts/FamiljenGrotesk-OFL.txt)
