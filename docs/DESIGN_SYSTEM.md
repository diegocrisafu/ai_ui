# SceneBreaker design system

The canonical design system is [root DESIGN.md](../DESIGN.md). It records the current route laboratory's built tokens, component states, responsive behavior, font files and documented limits. Machine-readable extensions and component previews live in [.impeccable/design.json](../.impeccable/design.json) (schema version 2).

The current world uses cool porcelain, graphite and ultramarine; Instrument Serif, Familjen Grotesk and Azeret Mono; the exact 1.25 type ramp with 150% leading; and 12/8/4 tracks. The former cream/forest/rust, Uncut Sans and Spline Sans description on this page belonged to the archived preset interface and is superseded. Its contrast figures, test counts and browser-verification claims do not describe the current build.
